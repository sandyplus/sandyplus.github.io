> 适用人群：人在国内、想低成本用上 Google Antigravity（反重力）的用户。

**路线总览**：干净美国 IP 养号 → 账号改美区免税州 → 找肖黄宇 5 元左右买 Gemini 会员 → 安装 Antigravity + AMT → 全程全局美国 IP 登录 → 手机扫码过风控。

教程内唯一需要"花钱"的步骤是第 3 步（约 5 元），其余全部是账号操作。

<!-- more -->

## 1. 概念与选型：这条"福利"是怎么回事

### 1.1 Antigravity（反重力）是什么

Google 在 Gemini 3 之后推出的 **agentic 开发平台**，官方组件包括：

* **Antigravity 2.0 桌面端**：日常对话、指挥智能体的主入口；

* **Antigravity IDE**：面向写代码的场景；

* **CLI / 编辑器插件 / SDK**：命令行、VS Code·JetBrains·Xcode 插件、Python SDK。

官方对个人开发者免费开放使用（支持 macOS / Windows / Linux），但**免费档的模型和额度有限**——绑定了 Gemini 会员（即 Google AI Pro 档订阅）权益的账号，额度会宽裕很多。这就是这条"福利"的核心：**用一个便宜的会员号去"蹬"反重力。**

### 1.2 为什么必须"美区 + 干净 IP"

谷歌的风控体系对两件事极其敏感：

| 变量 | 作用 | 不满足的后果 |
| --- | --- | --- |
| 干净美国 IP | 决定账号被判定为什么地区、是否异常 | 触发设备验证、扫码、发短信 |
| 账号地区 = 美国 | 服务可用性与稳定性 | 功能受限、频繁二次验证 |

整套流程说白了，就是围绕"**把环境伪装成一个安安静静在美国使用的正常用户**"来做的。

### 1.3 流程里的三个关键节点

1. **养号**（第 1 步）：干净 IP 连续登录一周，让账号历史记录全是"美国"；

2. **改区**（第 2 步）：账号地区改成美国免税州（顺手免税）；

3. **过风控**（第 5 步）：真触发了验证也不慌，手机扫码即可解锁。

> ⚠️ 事前提醒：风控策略更新很快，教程有时效性；低价渠道号有固有的翻车概率，**别拿主号上、别放重要数据**。

## 2. 第 1 步：找一个干净的美国 IP，养号一周左右

**目的**：让你要用来"蹬"反重力的这个谷歌账号，历史登录记录干干净净、全是美国 IP。

1. 准备一个**干净的美国 IP**（独享、住宅类节点更佳，避开万人共用的公共节点），全程**全局模式**；

2. 用这个环境**连续登录一周左右**（每天正常登录一下即可，比如刷刷 Gmail、YouTube）；

3. 核验 IP：打开 Gmail 网页版 → 右下角「**上次账号活动 / 活动详情（Details）**」→ 查看最近访问记录；

4. 判断标准：最近几次登录的 IP **显示为美国**，就说明当前环境合格。

> 💡 为什么要养？新号 + 环境突变 + 地区不符，是谷歌风控最喜欢抓的"三件套"。养号就是为了让账号拥有一份"美国用户"的历史画像。

***

## 3. 第 2 步：账号改到美国免税州（Oregon）

**目的**：把账号地区改成美国，顺手落在免税州（如 Oregon 俄勒冈），后续消费不加销售税。

1. 入口：Google **付款资料**（一般从 `pay.google.com` → 设置 → 付款资料 进入，以实际界面为准）；

2. 把**国家 / 地区改为 United States**；

3. 地址填写 **Oregon**（示例：Portland，邮编 97xxx 开头即可）；

4. 理由先选「**我住在这里（I live here）**」提交。

**如果不通过**：

* 不要同一天反复提交，**第二天再试**；

* 把理由换成其他说法，比如直接填下面这句话：

> "I want to switch to Google's US region for work purposes, as I need to use antigravity."

### 美国无销售税的州（就这几个）

| 州 | 说明 |
| --- | --- |
| **Oregon（俄勒冈）** | ✅ 首选，全州无销售税 |
| Delaware（特拉华） | 可用 |
| New Hampshire（新罕布什尔） | 可用 |
| Montana / Alaska | 部分城市有地方税，不作首选 |

## 4. 第 3 步：找肖黄宇花 5 元左右，买一个 Gemini 会员（18 个月）

整条路线里**唯一花钱的一步**：

1. 联系**肖黄宇**，花 **5 元左右**买一个 Gemini 会员；

2. 时长档：通常为 **18 个月**；

3. 到手形态以实际发货为准（常见的如：给你一个已开通会员的谷歌账号）；

4. 拿到后照本文第 1、2 步处理这个账号——**养号 + 改美区**（如果到手就是干净美区号，可跳过）。

> ⚠️ 三个底线：① 别拿主号去换号；② 到手后尽快确认权益（时长、是否美区）；③ 渠道号被回收的风险自担，重要资料不要放上去。

***

## 5. 第 4 步：下载安装 Antigravity 与 AMT，全程全局美国 IP 登录

### 5.1 安装 Antigravity

* 官网下载：`antigravity.google/download`（macOS / Windows / Linux 都有）；

* 下载页有 **Antigravity 2.0 桌面端、Antigravity IDE、CLI、SDK** 等组件，桌面端和 IDE 建议都装；

* 用第 3 步准备好的那个账号登录，全程保持**全局美国 IP**。

### 5.2 安装 AMT（多账号管理，强烈推荐）

**AMT** 是 LINUX DO 社区网友 uranplus 手搓的轻量级 Antigravity 多账号管理工具（GitHub：`wuyunfeng8/Antigravity-Manager`），定位是"**Antigravity 用户的桌面账号中枢：多账号配额雷达 + 接力管理器**"：

* **配额一览**：多个账号的用量、有效期一屏看清；

* **一键接力**：智能推荐并替换活跃账号，**省去反复验证的步骤**；

* **设备身份**：绑定硬件指纹、还原历史配置；

* 目前以 **macOS** 为主（M 系 / Intel 分开下载 .dmg，或 `brew install --cask antigravity-tools`，以仓库最新说明为准）；Windows 版社区已有自行编译的版本。

**使用方式**：先运行 Antigravity 客户端，再在 AMT 里点「Google OAuth 授权」完成账号添加（也支持粘贴 Token / 导入缓存），凭证只存在本地。

> 💡 小坑：如果你之前装过 lbjlaq 版的 Antigravity Tools，两个 App 的 Bundle ID 相同，启动台图标可能被覆盖——找不到 AMT 图标时，直接去「应用程序」文件夹里双击打开。

### 5.3 登录时的硬性要求

* **全程全局美国 IP**，登录过程不要断、不要跳节点；

* 顺利的话直接进入使用界面；一旦出现设备验证 / 扫码页面 → 不要慌，转到第 5 步处理。

## 6. 第 5 步：遇到风控——扫码验证解锁

### 6.1 你会看到什么

登录 / 使用反重力时，谷歌要求你做「**设备二次验证**」：电脑端出现验证入口和**二维码**，要求你用**受信任的移动设备**扫码验证（部分提示还会要求"发送短信"）。

常见触发原因：IP 不稳（脏 IP、跳区）、账号地区不符、新号活跃等。关键变量就三个：**IP 干不干净、账号是不是美区、手机端谷歌框架完不完整**。

### 6.2 解锁方法：任意安卓手机 +「Google」应用扫码

**不需要 Pixel、不需要三星**——普通安卓手机即可：

1. 手机登录 **Google Play** 和你的谷歌账号（与触发风控的账号一致）；

2. 用名为「**Google**」的那个 App（**注意不是 Chrome**，App 名字就叫 Google）的**扫码 / 智慧镜头（Lens）**功能，扫电脑屏幕上的二维码；

3. 实测**直接就通过，全程不用发短信**。

> 💡 补充：有网友反馈用谷歌浏览器（Chrome）扫码同样能解锁——**核心是手机端得是"完整的谷歌环境"**，具体通道可以多试。

### 6.3 验证成功的标志

1. 手机端出现「验证成功」提示；

2. 返回电脑端，出现一条 unlock 解锁记录，提示「**正在解锁**」；

3. 出现这个提示就代表**验证成功**，页面会自动跳转到**反重力使用界面**，之后就可以放心使用 Antigravity 了。

***

## 7. 重要注意事项

1. **别用主号**：低价渠道号有被回收 / 封禁的固有风险，重要资料别放；

2. **全程别跳区**：美国 IP 从养号一直保持到最后，中途"裸奔"很容易触发风控；

3. **教程有时效**：谷歌风控更新很快，遇到卡点先看参考链接里的社区原帖；

4. **验证就用扫码路线**：任意安卓手机 +「Google」应用（不是 Chrome）扫二维码，实测免短信直接过。
