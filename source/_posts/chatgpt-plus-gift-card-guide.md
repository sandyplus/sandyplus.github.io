## 1. 概念与选型：为什么选 Apple 内购

### 1.1 两条渠道对比：Apple（App Store） vs Google Play

ChatGPT Plus 在手机上有两条订阅计费渠道，**互不通用**：

| 对比项 | ✅ Apple 内购（App Store） | ⚠️ Google Play（安卓） |
| --- | --- | --- |
| 计费方 | Apple（账单走 Apple ID） | Google（账单走 Google 账号） |
| 国内可行性 | 高：支付宝买美区礼品卡即可 | 低：需要谷歌框架 + 科学上网 + Play 环境 |
| 礼品卡渠道 | 成熟（支付宝官方渠道） | 渠道少，假卡 / 黑卡风险高 |
| 账号风控 | 宽松：美区 ID + 礼品卡是被验证最多的路径 | 严格：新号 / 地区不一致易触发验证 |
| 低价区陷阱 | 无（美区 ID 规则清晰） | 低价区账号订阅是明显异常信号，双重风控 |
| 支付暴露 | 扣商店余额，不绑卡、不填账单 | 常被要求补充支付资料 |

**结论：选 Apple 内购。**

- Apple IAP 渠道成熟、审查宽松、礼品卡购买方便；
- Google Play 对国内用户是 "风控重灾区"，低价区账号（土耳其、印度等）订阅 Plus 容易被 OpenAI 和 Google 双重标记；
- 你有 iPhone/iPad/Mac 任一设备即可完成，订阅后**任意设备登录同一 ChatGPT 账号都能用 Plus**。

### 1.2 一个 Apple ID 只能对应一个 ChatGPT Plus 账号

这是最关键的一条规则，很多人栽在这里：

- **同一 Apple ID 对同一个 App 只能存在一份订阅**；
- 订阅凭证**同时绑定 Apple ID 和订阅时登录的 ChatGPT 账号**（官方 "恢复购买" 说明确认：必须用订阅时那个账号登录才能恢复权益）；
- 所以：**一个 Apple ID 只能给一个 ChatGPT 账号升级 Plus**。想给第二个账号（比如媳妇的）升级，必须用**另一个 Apple ID** 走一遍完整流程；
- App Store 余额**不可共享、不可转账**，家庭共享也救不了（账户余额不参与共享，ChatGPT 这类账号绑定型服务基本不支持订阅共享）。

> 💡 结论：
>
> **一人一套**
>
> —— 自己的 Apple ID + 自己的 ChatGPT 账号 + 自己的礼品卡。别想着一个 ID 管两个账号。

### 1.3 账号安全建议（付费前必读）

- 用**历史干净**的 ChatGPT 账号订阅（没有破解、薅羊毛、代充等违规记录的号）；
- 有过违规历史的账号即使没被封，也存在 "延迟清算" 风险：一旦开始付费、绑定支付，可能触发复审，届时订阅费打水漂且余额不可退；
- 长期闲置的账号**不影响安全**，重新登录正常使用即可；
- 订阅绑定的是**登录时那个 ChatGPT 账号**，切换账号不会转移权益。

## 2. 准备一台 iPhone，App Store 登录美区 ID

### 2.1 确认 / 准备一个美区 Apple ID

- 已有美区 ID：直接用（本文案例：`shiyong05@gmail.com`）；
- 没有：到 `appleid.apple.com` 注册，国家 / 地区选 **United States**，支付方式选 **无（None）**，邮箱验证即可；
- **不要**把中国区 ID"改成" 美区（需要美国支付方式、易触发审核）—— 直接注册新的最干净；
- **不要**买网上的共享 / 代注册美区 ID—— 被找回、被风控概率高。

### 2.2 如何确认当前 Apple ID 是美区

- **iPhone/iPad**：打开 App Store → 右上角头像 →「查看账户」→ 看**国家 / 地区**；
- **Mac**：打开 App Store → 左下角姓名 → 账户 → 看**国家 / 地区**；
- **网页**：`appleid.apple.com` 登录后查看；
- 判断标准：国家 / 地区显示 **United States / 美国**、价格显示 **\$（美元）** 即为美区；显示 **China / 中国**、价格 **¥** 即为中国区。

### 2.3 只在 App Store 切换，不动 iCloud（关键！）

- ✅ **只做**：App Store 里退出当前商店账号 → 登录美区 ID；
- ❌ **不要做**：在 iPhone「设置」或 Mac「系统设置」里退出整个 Apple ID—— 那会退出 iCloud，导致照片、备忘录等数据迁移问题，且与订阅无关。

**iPhone 操作：**

1. 打开 App Store → 右上角头像；
2. 拉到页面最底部 → 点「退出登录」（只退商店，不影响 iCloud）；
3. 再点头像 → 用**美区 ID** 登录；
4. 点头像 →「查看账户」→ 确认**国家 / 地区 = United States**。

**Mac 操作（可选）：**

1. 打开 App Store → 左下角姓名 → 账户设置；
2. 找不到「退出登录」时：看**窗口左下角**（和右下角 "完成" 对称），或屏幕**顶部菜单栏 → 商店 → 退出登录**；
3. 退出后点「登录」输入美区 ID。

## 3. 改免税州地址（土豪跳过）

### 3.1 为什么要改

Apple 按**账单地址所在州**收销售税。马萨诸塞州（6.25%）这类有税州，订阅时会被加税：

- Plus 月费 $19.99 + 6.25% 税 ≈ **$1.25 / 月**，一年约 **$15**；
- 免税州 = 订阅不加税。

### 3.2 美国无销售税的州（仅 5 个）

| 州 | 说明 |
| --- | --- |
| **Oregon（俄勒冈）** | ✅ 首选，全州无销售税 |
| Delaware（特拉华） | 可用 |
| New Hampshire（新罕布什尔） | 可用 |
| Montana / Alaska | 部分城市有地方税，不作首选 |

### 3.3 在哪里改（注意：网页版改不了）

❌ `appleid.apple.com` 网页的 "付款与配送" 里**没有**账单地址入口（"添加付款方式" 是绑卡，"配送地址" 是 Apple Store 实体购物用的，都不是订阅账单地址）。

✅ 正确入口在**设备端**：

- **iPhone**：设置 → 顶部你的名字 → 媒体与购买项目 → 查看账户 → 点「**账单寄送地址**」；
- **Mac**：App Store → 左下角姓名 → 账户设置 → 点「**账单寄送地址**」。

### 3.4 地址怎么填（虚构示例，格式自洽即可）

> 以下为**虚构示例地址**，仅用于 Apple ID 账单计费；Apple 一般不验证实体。
>
> **只用于 Apple ID，不要用于其他需要真实地址验证的场景。**

| 字段 | 填写内容 |
| --- | --- |
| 街道 | `1234 NW 5th Ave, Apt 207` |
| 城市 | `Portland` |
| 州 | `Oregon` |
| 邮编 | `97205`（Oregon 为 97xxx/98xxx 开头，需与城市匹配） |
| 国家 / 地区 | `United States`（保持不动） |

## 4. 支付宝买礼品卡 → App Store 兑换

### 4.1 支付宝买卡

1. 打开支付宝，搜索**礼品卡**相关关键词，或直接搜索以下内容（以支付宝内实际显示的官方入口为准）：

```
# https://www.wmslz.com/s/rWjLcxH3433#👉復值👈此消息，打开👉支付保👈搜，体验PockytShop小程序  q:/e CZ0641 $143
```
2. 选 **App Store & iTunes 充值卡**，地区选 **美国（United States）**；
3. 金额建议 **$25 以上**（Plus 约 $20 / 月 + 税，$25 够首月还留余量）；
4. 付款后**复制兑换码**并妥善保存（兑换码等于现金，**不要发给任何人**）。

> ⚠️ 只买官方渠道的卡，避开淘宝低价代购、来源不明的点卡。

### 4.2 App Store 兑换

1. 打开 iPhone 的 App Store → 右上角头像；
2. 点「**兑换充值卡或代码**」；
3. 选择手动输入，粘贴兑换码；
4. 成功后余额到账（可在「查看账户」里看到余额）。

## 5. 下载 ChatGPT 并登录你的账号

1. 在 App Store 搜索 **ChatGPT**，下载官方应用（OpenAI 出品，图标为黑底白花）；
2. 打开 ChatGPT，**用你要升级的账号登录**（本文案例：`shiy05@proton.me`）；
3. 确认登录的是**干净、打算长期使用**的那个账号 ——Plus 权益会绑定在这个账号上。

> 💡 设备提醒：订阅绑定 ChatGPT 账号而非设备。用 iPhone/iPad 完成订阅后，**安卓手机登录同一账号照样用 Plus**，不受影响。

## 6. 升级 Plus：选 Apple 内购

1. 在 ChatGPT App 内，点左上角菜单 → 头像 → 或对话顶部的「升级」入口；
2. 选择 **Apple 内购（In-App Purchase）** 方式升级；
3. Apple 弹出订阅确认页面，核对：
   - 扣款账号是**美区 Apple ID**；
   - 金额 **$19.99 / 月**；
4. 确认后余额自动扣款，订阅生效。

> ⚠️ 如果订阅按钮灰显、提示 "In-app purchases are currently unavailable"：Apple 正在激活订阅功能，**等最多 48 小时**再试。

## 7. 遇到审核：提交审核并等待

### 7.1 这是什么

「购买未完成 / 提交审核到 Apple」= **Apple 把购买挂起，进入账号审核（Pending Approval）**。这不是失败，与 OpenAI 无关，是 Apple 在放行前审查账号。

常见触发场景（新手全占）：美区 ID 首次消费 + 刚改账单地址 + 第一次用礼品卡余额订阅。

### 7.2 怎么做

| 时间 | 动作 |
| --- | --- |
| 现在 | ① **不要再点升级**（避免多个挂起订单）；② 检查 Apple ID 邮箱（如 `shiyong05@gmail.com`）有没有 Apple 验证邮件，有则按邮件操作；③ 检查 App Store 账户余额是否完整；④ 可重启设备、退出重登 App Store |
| 24–48 小时 | 耐心等待，多数 **24 小时内**自动通过；通过后订阅自动生效、余额才被扣 |
| 超过 48 小时 | 联系 Apple 支持：`reportaproblem.apple.com` 或 `support.apple.com`，说明 "美区账号首次内购订阅 ChatGPT Plus 被挂起"，附账号邮箱和报错截图 |

### 7.3 审核期间的钱

- 审核期间**不会扣款**，只有通过那一刻才扣；
- 万一审核不通过：购买被取消，**礼品卡余额原封不动退回账户**——App Store 余额**不设过期日、不会消失**，可再试或用于其他购买；
- **不存在 "钱浪费了" 的结局**。

## 8. 常见问题 FAQ

**Q1：我能不能用一个 Apple ID 给自己和媳妇各买一份 Plus？**

不能。一个 Apple ID 对同一 App 只有一份订阅，且订阅绑定订阅时登录的 ChatGPT 账号。给第二个人升级必须用**另一个 Apple ID + 另一个 ChatGPT 账号 + 另一张礼品卡**。

**Q2：用同一个美区 Apple ID 的礼品卡余额，能不能帮别人的账号付款？**

不能。余额属于该 Apple ID，不可共享、不可转账。Apple 侧还警惕 "一 ID 多账号" 的代购特征，风险高。

**Q3：网页端能不能用 App Store 余额订阅？**

不能。App Store 余额只用于 iOS/App Store 渠道订阅；网页端订阅需要绑外币卡（OpenAI 直接计费）。两者是不同体系。

## 9. 重要注意事项

1. **兑换码保密**：等于现金，不要发群里、不要截图外传；
2. **不要薅羊毛 / 代充**：破解、合租、代充都是 OpenAI 明令禁止行为，封号风险 "延迟清算"，省小钱亏大钱；
3. **只用干净账号订阅**：有违规历史的账号别拿来付费；
4. **别买共享美区 ID**：自己注册几分钟的事，共享号被找回 / 风控概率极高；
5. **一人一套**：给家人订阅用独立 Apple ID + 独立 ChatGPT 账号 + 独立礼品卡；
6. **订阅管理**：iPhone「设置 → 顶部名字 → 订阅」或 App Store 头像 → 订阅，可查看 / 取消自动续费。
